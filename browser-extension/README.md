# Flowsink Browser Monitor — Chrome Extension

Privacy-first browser telemetry extension for [Flowsink](../../README.md) Activity Engine.

## What it does

- Watches Chrome tab lifecycle events: **activated**, **created**, **updated**, **removed**.
- Sends anonymous tab telemetry to the local Flowsink backend:

| Event | Trigger |
|---|---|
| `TAB_CREATED` | New tab opened |
| `TAB_UPDATED` | URL / title / load status changed |
| `ACTIVE_TAB_CHANGED` | User switched to another tab |
| `TAB_CLOSED` | Tab closed |

## What it does NOT collect

No passwords, keyboard input, form content, page HTML, cookies, or credentials.
All URL query parameters are stripped before sending (privacy by design).

## Install (Windows)

**Normal users:** double-click `install_browser_extension.bat` (or the `.py`).
The installer generates/updates this directory, detects Chrome, and guides you
through the one manual step Chrome requires: **Load unpacked**.

**Manual install (dev):**

1. Open `chrome://extensions/`
2. Enable **Developer mode** (top-right)
3. Click **Load unpacked**
4. Select this `browser-extension` folder
5. Verify backend is running, then browse any website

## Backend contract

Extension POSTs to:

```
POST {api_base_url}/api/browser/telemetry
Content-Type: application/json

{
  "events": [
    {
      "kind": "browser_navigation" | "browser_tab_focus" | "browser_tab_close",
      "source": "extension",
      "timestamp": "2026-08-12T01:00:00Z",
      "device_id": "DESKTOP-ABC123",
      "tab_id": "42",
      "domain": "youtube.com",
      "url": "https://youtube.com/watch",
      "title": "YouTube"
    }
  ]
}
```

## Offline behavior

- Queue cap: **100 events** (FIFO — oldest dropped first, never infinite).
- Retry: exponential backoff 1s → 2s → 4s → … max 60s.
- Dedupe: same event type + tab + domain within 1.5s is discarded.
- On backend recovery, queued events are flushed automatically.
